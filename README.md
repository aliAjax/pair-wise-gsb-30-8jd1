# 油品配送计划

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Pinia、Element Plus
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

## 到站回单闭环

配送单记录司机，流转与回单规则如下：

1. **创建配送单**：选择在聘且无未结差异的司机，待发车 →（发车）→ 运输中。
2. **司机到站上报**：上报实际过磅吨数、油温、封签状态与封签号，配送单进入「待回单」。
3. **值班员审核**：可确认，或填写原因退回；退回后司机修改可重新上报。
4. **差异处理**：过磅偏差超过 ±2%（短装/超装）或封签破损、缺失，确认时自动生成差异单挂到该司机名下；未结清前该司机不能再排新配送（也不能发车），结清后自动恢复。
5. **到站**：值班员正常确认（即使带差异）后配送单才变为「已到站」。

页面页签显示待确认回单与未结差异数量；当前页签、值班员姓名、回单定位及全部台账均存 localStorage，重开页面可接着办。

## 模块划分（分开整理）

- `src/config/receiptRules.ts`：回单规则（2% 偏差、油温参考、封签、差异判定）
- `src/config/driverRules.ts`：司机资格规则
- `src/store/drivers.ts`：司机档案本地台账（`hxwlfront-19-drivers`）
- `src/store/ledger.ts`：配送单与差异单本地台账（`hxwlfront-19-ledger-v2`，自动迁移旧版数据）
- `src/store/ui.ts`：页签与待办定位（`hxwlfront-19-ui`）
- `src/components/`：配送计划、回单办理台、差异台账、司机资格、规则手册

原有油站筛选与状态流转（待发车 → 运输中 → 到站）保留，仅在到站前插入回单环节。数据默认保存在浏览器 localStorage，方便后续扩展接口、权限、图表或地图能力。
